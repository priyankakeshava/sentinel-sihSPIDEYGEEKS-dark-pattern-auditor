# Phase 2 / Future Scope

Later phases can expose the same Sentinel evidence engine to consumers through a browser extension and expand the detector library toward all 13 CCPA dark-pattern categories.

Other later extensions:
* stronger multilingual ML
* more Indic-language coverage
* larger website crawler pool
* multimodal UI analysis
* production-scale evidence storage
